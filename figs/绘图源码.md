## 图 1 总体技术路线

![图 1：总体技术路线](fig1_system_overview.png)

```mermaid
flowchart TB
    subgraph IN["输入"]
        A["每帧：相机图像 + 激光雷达点云 + 外参"]
    end
    subgraph DET["目标识别"]
        B["开集目标检测<br/>文本提示 → 2D框 → 掩膜 → 3D点 → 包围盒"]
        C["线状目标检测<br/>2D线分割 → 骨架 → 3D曲线拟合"]
    end
    subgraph RNG["三维测距"]
        D["传感器距离 / 目标间最近距离"]
    end
    subgraph OUT["输出"]
        E["识别结果 + 距离 + 可视化"]
    end
    A --> B
    A --> C
    B --> D
    C --> D
    D --> E
```

## 图 2 开集目标检测流程

![图 2：开集目标检测流程](fig2_open_set_detection.png)

```mermaid
flowchart TB
    A["图像 + 文本提示，如 person / 挖掘机"] --> B["开集二维检测器<br/>YOLO-World / OWLv2"]
    B --> C["候选二维框 + 置信度"]
    C --> D["SAM2 像素级掩膜精化"]
    D --> E["点云投影到像面，选掩膜内点"]
    E --> F["深度歧义处理<br/>最近表面 / 单目深度形状模板匹配"]
    F --> G["目标三维点集"]
    G --> H["PCA 定向包围盒<br/>中心 / 尺寸 / 姿态"]
```

## 图 3 线状目标检测流程

![图 3：线状目标检测流程](fig3_linear_target_detection.png)

```mermaid
flowchart TB
    A["图像 + 点云 + 外参"] --> B["① TTPLA 二维线分割"]
    B --> B1{"掩膜面积合理?"}
    B1 -- 否 --> X1["跳过：误检"]
    B1 -- 是 --> C["② 骨架 → 有序二维中心线"]
    C --> D["③ 骨架膨胀宽带 → 落入带内的点云候选"]
    D --> E["④ inlier 选择<br/>线性度 + 深度聚类"]
    E --> F{"inlier 足够?"}
    F -- 否 --> X2["跳过：点数不足"]
    F -- 是 --> G["⑤ 三维曲线拟合 + 稠密采样"]
    G --> H["⑥ 端点切线外推"]
    H --> I["输出三维曲线"]
```

## 图 4 线状目标 inlier 选择核心逻辑

![图 4：线状目标 inlier 选择核心逻辑](fig4_linear_inlier_selection.png)

```mermaid
flowchart TB
    A["带宽内候选点"] --> B["每点局部邻域 PCA"]
    B --> C["线性度 = (λ0−λ1)/λ0"]
    C --> D{"线性度 ≥ 阈值?"}
    D -- 否 --> X["剔除：二维背景"]
    D -- 是 --> E["保留一维候选<br/>线状目标 + 墙/杆边缘"]
    E --> F["按深度排序，算相邻间隔"]
    F --> G["显著间隔 = 中位数 + 系数·MAD"]
    G --> H["在显著间隔处切簇"]
    H --> I["取最近且点数足够的簇<br/>跳过更近孤立点"]
    I --> J["线状目标 inlier"]
```
